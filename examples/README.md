# Historical examples and test fixtures

These programs predate the current release. Selected files power the website's
[archive gallery](https://kilnstudio.tools/gallery/archive/); others are retained
studies or engine test fixtures. They are not a recommended modeling curriculum
or a set of accepted reference assets. Preserve their original source and credits
when using them for compatibility checks.

For newer authored work, start with [asset packs](../packs/README.md), including
Troy, Farm, Vehicles, Bridge and Foundry. Their saved sources retain the engine
and material information required to reproduce them. Interactive application
code lives separately in [scenes](../scenes/README.md).

This folder is not included in the npm package or copied into generated authoring
workspaces. Discovery serves maintained helper examples and recipes from
`src/discovery/`; it does not index these full asset programs. Author in a separate
workspace and use Discovery for current API guidance.

Do not remove or relocate files without checking engine tests, the site asset
builder, archive links and provenance records. A successful replay establishes
compatibility, not visual quality.
