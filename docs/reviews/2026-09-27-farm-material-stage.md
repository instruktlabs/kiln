The batch exposed two reusable issues:

- CLI save lacked MCP's declared model/harness/author fields. The CLI now forwards
  these through the existing registry contract. No MCP schema or saved manifest was
  changed; requested and confirmed effort remain explicit provenance notes.
- Retained animation names collided when several assets used `Walk` or
  `ArticulationProbe`. `composeSceneGLB` now supports opt-in instance-qualified names,
  preserving default names, source bytes, target nodes and keyframes. The composed
  scene can select each asset's clips without changing individual model sources.
