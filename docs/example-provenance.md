# Gallery credits and build records

The [historical gallery](https://kilnstudio.tools/gallery/archive/) preserves saved
work from different models, briefs and review processes. It is not a benchmark or
a source of accepted example geometry. Current packs and scenes have their own
[delivery records](https://github.com/instruktlabs/kiln/blob/main/packs/README.md).

Archive programs, sidecar credits, retained revisions and poster receipts come
from pinned Git history. See [archive restoration](examples.md#historical-collection).
The old promotion and poster-authoring scripts are preserved in that history;
they are no longer active publishing commands.

The site rebuilds each selected archive program and publishes its exact source
beside the GLB. Build checks verify source hashes, retained revision links and
poster records. Rendered GLBs can differ across platforms, so each build records
its engine, dependencies and platform. A historical poster's source/image checks
do not claim byte identity with every later GLB rebuild.

Credits distinguish a recorded run from attribution declared in source. Missing
context remains marked as unrecorded. Supplied examples, reviewer feedback and
maintainer edits do not become independent model output merely because a later
build succeeds. Asset quality still requires actual review.

Recent assets are maintained in separate authoring workspaces and delivered as
versioned packs. Keep exact authored source, saved revisions, dependencies and
licenses with those deliveries; do not promote new work into the archived corpus.
