# v0.9 scene and vehicle previews

Captured on 2026-10-01 from the integrated local site, using the actual scene and
gallery renderers. Scene captures fill a 1920 x 1080 canvas with controls hidden;
vehicle captures contain only the gallery canvas. No scene content was retouched.

- `farm-v09.png`: Farm r36-local-review, elevated view across the farm buildings and fields.
- `golden-gate-v09.png`: Golden Gate g9, daytime aerial view over the water, framing the full main span.
- `foundry-campus-v09.png`: Foundry ff3-review2, exterior view along the factory campus.
- `foundry-floor-v09.png`: the same Foundry build, inside the container-transfer aisle. The scene remains an in-production preview.
- The six vehicle images use the gallery's public paint selector. The downloadable
  original GLBs are unchanged. `cars.json` records each asset revision and colour.

`capture.json` records the scene runtime hashes and browser. The README places the
Foundry exterior and interior side by side; they are separate views of the same scene.

Scene source lives in `scenes/`; pinned asset and runtime inputs are recorded in
`site/src/data/scene-packs.json` and `site/src/data/scene-inputs.json`.
Asset licences and author provenance remain attached to each scene's pack and downloads.
